# Provenance rules

Every audible layer in Gallop carries a `provenance` block in
`site/data/cases.json`. The validator refuses a case without one.

## Stem classes

| `provenance.class` | Origin | Licence | Used for |
|---|---|---|---|
| `synthesized` | Generated by `tools/synth_stems.py` from published characteristics; tuned by ear against the program manikin | CC BY 4.0, Brendan Hood | Primary teaching material |
| `recorded_annotated` | A single cycle cut from a PhysioNet record where the finding matches the dataset's own expert annotation | ODC-By 1.0, inherited from the dataset | Real murmur examples; "hear the real thing" clips |
| `recorded_clinician_labelled` | A single cycle cut from a PhysioNet record; finding assigned by a named reviewer | ODC-By 1.0, inherited | Adult examples with no dataset annotation; hard mode |

A `synthesized` layer cites its basis (`provenance.basis`), or `n/a` for a
boundary cue. A `recorded_*` layer names the dataset, record ID, licence, and
the annotation or the reviewer who labelled it, plus any time-stretch factor.

## The manikin rule

The program manikin's sound library is vendor IP. It is never recorded,
sampled, transcribed, copied, or redistributed, in whole or in part. It is
used only as a listening reference while tuning synthesized stems by ear.

## Reviewer sign-off

A case is a draft until a clinical reviewer has listened to it and set
`reviewed_by` and `review_date`. Draft cases show a "draft" pill in practice
mode and are excluded from quiz mode. Once reviewed, a case is never edited in
place: copy it, bump the `id` with a suffix (`-v2`), and review the copy, so a
learner's stored progress still points at the exact case they heard.
